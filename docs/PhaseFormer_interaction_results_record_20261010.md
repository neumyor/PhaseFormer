# PhaseFormer-L 交互与融合实验结果记录

记录日期：2026-10-10。本文固定记录当前会话已整理并核验的结果，不新增训练或测试。

## 1. 范围与读数结论

正式 test 表覆盖 ETTh1、ETTm2、Weather × H96/H720，lookback=720。一个 dataset×horizon 是一个任务 setting；每个交互任务有 seed2021/2022 两次独立初始化训练。方法编号 A/N/L/F/C/M 则表示同一任务下的不同架构或控制，不能把方法编号与任务 setting 混为一谈。

目前保留 B0：原低秩分支 + 无 token 消息 + 静态水平/波形双分量融合。新增交互没有证明跨任务、跨 seed 的稳定实际收益。M1 的六任务平均 MSE 比 B0 低约0.095%，但 MAE 高约0.017%，仅4/12个 seed-setting 的 MSE胜出；不能据此升级默认架构。相对 Golden，M1为单指标读数较低，不是双指标提升。

本记录包括五种早期 Attention、八种归一化/Null/选择性写入、四种低秩消息、两种长预算 Pre-Norm、两种上下文候选和中心化调制；其配对基线、论文参照一并列出。C2是phase-only机制对照，不应称为跨分支交互。动态输出Gate、warm-start和冻结探针另列范围说明，不混入正式test架构表。

## 2. 指标与比较口径

- 每个test指标使用该setting全部sample×forecast step×channel的误差总和除以元素数；使用原test划分，train-fit标准化，shuffle=False、drop_last=False。
- 先平均同一task的两个seed，再将六个task等权平均；不按数据集长度或窗口数量给某任务更大权重。
- MSE/MAE显示四位小数；delta使用未舍入数据，显示三位百分比。Golden原始来源仅有三位小数，显示四位并不增加来源精度。
- 本文 `Δ=(candidate/Golden-1)×100%`，负值表示误差降低；这是误差变化，和金标准文档中“正号为提升”的improvement_rate符号相反。
- 汇总delta用汇总均值之比，逐task delta用该task值之比；不是逐setting百分比的平均，不能直接代入之前的平均相对MSE推进门槛。
- Golden来自 [原始金标准](PhaseFormer_gold_standard.md)。六任务均值MSE=0.2935、MAE=0.3323333333。P0/P1/P2来自原E14三seed均值；交互实验为两个seed，预算和融合不同。数值对照不等于独立架构因果比较。

## 3. i0 与 b0 的区别

i0和b0的phase主干、低秩E/D、last-value anchor与输入结构相同；独立训练后的权重不保证相同。二者均不在trend token和phase token之间传消息。两者都在RevIN归一化坐标中融合，最后还原尺度。

| 项目 | A0/N0/F0：i0 | B0：b0 |
|---|---|---|
| 融合参数 | 每变量一个静态权重g | 每变量水平/波形两个静态权重 |
| 融合对象 | 完整预测统一混合 | 每P24周期均值与去均值波形分别混合 |
| 随样本/未来cycle动态变化 | 否 | 否 |
| 单变量公式 | `(1-g)*phase + g*trend` | 水平用g_level、波形用g_shape |
| 多出的参数 | 无额外分量参数 | 每变量一个shape_bias_delta，共C个参数 |
| 原有测试预算 | A0/N0为8轮；F0最多30轮 | 最多30轮/patience8 |

b0可以在水平上更多相信trend、波形上更多相信phase。两个权重相等时，b0退化为单门融合。两者共同初始权重0.2，shape差值初始为0；权重在训练中学习，评估时固定。A0与N0虽都叫i0，来自不同配对实验、初始化记录，数值不同；F0是单门的长预算对照。不能把8轮i0与30轮b0的全部差异归因为融合公式。

代码：[分量融合](../src/models/lowrank_fusion.py)、[PhaseFormer基线融合](../src/models/PhaseFormer.py)。

## 4. 每种方法做了什么

以下T是原r维低秩历史编码，Z是最终phase表征。名字不约束T只能含趋势或Z只能含周期；两分支均来自同段历史。P->T消息在原低秩D解码前写入；T->P在最终phase predictor之前写入。

| 编号 | 具体修改 | 比较目的与基线 |
|---|---|---|
| G/P0/P1/P2 | 原始Golden、论文phase-only、dense L、压缩L q1/8 | 已有参照，不是本轮新训 |
| A0/N0/F0 | 原r=H/8 E/D与单静态输出门，无消息 | 分别对应早期Attention、Norm、长预算组 |
| A1 | trend作为query读取phase的attention消息 | 判断phase能否补低秩预测；对A0 |
| A2 | phase读取一个trend key/value后更新 | 单key的attention权重恒为1，本质是广播条件；对A0 |
| A3 | P->T与T->P并行更新 | 判断双向是否互补；对A0 |
| A4 | 两轮交替P->T->P | 判断反复传递是否有用；对A0 |
| A5 | 合并trend与phase token做联合attention | 判断联合建模是否优于晚期融合；对A0 |
| N1/N5 | P->T/T->P的`LN(token+message)` | Post-Norm接收更新控制；对N0 |
| N2/N6 | 对交互输入归一化后保留原token并加消息 | Pre-Norm vs Post-Norm；同时对N0 |
| N3/N7 | Pre-Norm消息增加零初始化可学习缩放 | 初始保留基线表征；和N2/N6及N0比较 |
| N4 | 在N3读取中增加最终零消息null选项 | 是否应拒绝phase信息；机制基线N3、全架构N0 |
| N8 | 在N7中逐phase决定trend消息接收量 | 选择性写入vs广播；机制基线N7、全架构N0 |
| B0 | 无消息，静态level/shape分别融合 | L/C/M组统一无交互参照 |
| L1 | `t'=t+B*A*mean_phase(Z)` | 宽度k=min(2,r,d)加性P->T；对B0 |
| L2 | `t'=t+B*(A*mean_phase(Z)-S*t)` | 接收状态差形式，不能直接解释为可识别滤波创新；对B0 |
| L3 | `Z'=Z+B*A*t`，共同消息广播所有phase slot | 最终共享线性predictor下直接改变cycle水平；对B0 |
| L4 | `Z'=Z+Z*(B*A*t)` | trend按特征调制phase；对B0 |
| F1 | N6同类Pre-Norm但最多30轮，单门 | 预算确认；对F0，不混入N6的8轮记录 |
| F2 | 长预算T->P Pre-Norm + 静态双分量融合 | 对F1看融合，对B0看交互 |
| C1 | `Z'=Z+B*(A*t-C*mean_phase(Z))`，共享输出B | phase上下文条件化的cycle水平消息；对B0及L3 |
| C2 | `Z'=Z-B*C*mean_phase(Z)`，没有t输入 | phase-only对照，区分自身读出与跨分支贡献 |
| M1 | `Z'=Z+(Z-mean_phase(Z))*(B*A*t)` | 约束直接修正不改cycle均值；对B0及L4 |

公式中`*`在A/B/C/S映射之间表示矩阵复合，在Z与调制消息之间表示逐元素乘法；T->P消息按phase slot广播。L/C/M的额外线性输出映射零初始化，公共随机主干参数配对；从头全参数联合训练。M1只保证固定共享线性预测头下直接写入的cycle均值约束，不保证独立联合训练后的主干水平预测相同。上述操作发生在不同表示和接口，不能只按方向名称视为同一实验。

实现：[Attention](../src/models/lowrank_interaction.py)、[Norm配置](../scripts/run_lowrank_interaction_stage2.py)、[低秩消息](../scripts/lowrank_token_interaction/model.py)、[上下文](../scripts/phase_context_interaction/model.py)、[中心化调制](../scripts/centered_mod_interaction/model.py)。

## 10. 解释边界

本轮扩展是用户明确要求的完整test读取与固定缺失设置补训，不按test调参或拼接dataset/horizon赢家。此前test已经启发研究方向，validation也重复用于checkpoint/机制选择；不能称为盲测或无偏泛化。两个seed不足支持显著性，重叠窗口不独立。少量均值变化或理想oracle不证明trend/phase信息有用或无用；当前保留B0是基于已测实例的效果、稳定性和成本判断。
