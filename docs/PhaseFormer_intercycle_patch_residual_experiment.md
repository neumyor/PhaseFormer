# ICPT 周期间周期残差实验：完整闭环

## 1. 实验要验证的设想

PhaseFormer 主要从“同一相位跨周期聚合”的方向建模；RCRF 当前的 NLinear 残差头则负责补偿近期轨迹，但没有显式建模完整周期如何逐周期演化。本实验提出 Inter-Cycle Patch Transformer（ICPT）：把每个 `P=24` 的完整周期块作为 token，沿周期间轴建模形状、幅值和水平变化，再替换 RCRF 中的 NLinear 残差头。

核心假设是：ICPT 与 PhaseFormer 分别观察周期矩阵的“周期间”和“相位间”两个方向，融合后应比 `RCRF + NLinear` 更好；只有无位置编码的 ICPT 架构先通过筛选，才有必要比较不同位置编码。

## 2. 实验的整体计划

实验固定 PhaseFormer 主干、RCRF 门控、`P=24`、数据划分、损失、学习率和训练预算，仅替换 residual head：

- A2：当前 `RCRF + NLinear`，直接基线；
- A3：重复最近完整周期，检验简单周期 persistence；
- A4：CycleNet-style 周期模板加线性残差；
- A5：`RCRF + ICPT-none`，检验不含位置编码的新架构。

Stage A 在 ETTh2-720、ETTm2-96、Electricity-336、Weather-336 上使用 seed 2021、30% 训练数据、最多 8 epoch，并且只读取 validation。A5 只有满足以下任一预注册条件才进入位置编码筛选：八个 `A5/A2` 指标比值均值 `<1` 且最差值 `≤1.01`；或至少 3/4 setting 的 MSE、MAE 同时改善，其他 setting 最大回退 `≤0.5%`。

原计划的 Stage B/C/D 分别用于十种位置编码筛选、六 setting×三 seed 正式 test 和机制/样本消融；若 Stage A 失败则全部停止，不能靠继续搜索位置编码掩盖基础架构问题。

## 3. 每个实验的实现方式和结果

ICPT 将长度 720 的输入重排为 30 个周期 token，以最近完整周期为锚点，用一层 encoder 和一层 decoder（`d_model=32`、4 heads、FFN=64）预测未来周期增量；所有通道共享同一组参数。输出投影零初始化，使初始预测严格等于重复最近周期。Stage 0 的 124 个既有测试和 15 个 ICPT 新测试全部通过；十种 PE 均可有限值前反向传播并收到梯度，四个 horizon、862 通道、无未来标签泄漏和 ETTm2 5% smoke test 均通过。

Stage A 共完成 16 个 validation-only run。结果如下；“A5 改善率”以 A2 为基准，正数表示误差降低：

| Setting | A2 RCRF-NLinear | A3 RepeatCycle | A4 CycleNet-style | A5 ICPT-none | A5 MSE/MAE 改善率 |
|---|---:|---:|---:|---:|---:|
| ETTh2-720 | 0.63207 / 0.55913 | 0.63928 / 0.55241 | 0.62422 / 0.55686 | **0.60690 / 0.54418** | **+3.98% / +2.67%** |
| ETTm2-96 | **0.11817 / 0.23265** | 0.15772 / 0.28119 | 0.11816 / 0.23262 | 0.15099 / 0.27222 | −27.77% / −17.01% |
| Electricity-336 | **0.13936 / 0.23060** | 0.16031 / 0.24731 | 0.13942 / 0.23071 | 0.16461 / 0.24755 | −18.12% / −7.35% |
| Weather-336 | 0.54072 / 0.36653 | 0.86699 / 0.49921 | **0.53945 / 0.36626** | 0.68911 / 0.43357 | −27.44% / −18.29% |

关键分析：

- A5 的八项 `A5/A2` 比值均值为 **1.137**，最差为 **1.278**；只有 1/4 setting 双指标改善，明确未通过 Stage A 门槛。
- A5 只在 ETTh2-720 上出现正向信号。这可能与长预测任务更适合周期块压缩，或 ETTh2 的 NLinear 参数量更大有关，但这里只有单 seed、子集 validation，不能据此断言 ICPT 在长预测上普遍有效。
- A3 除 ETTh2 外均明显退化，说明简单复制最近周期不足以替代 NLinear。A4 与 A2 的八项差异都在约 1.3% 以内；由于 A4 本质上仍保留 `history→future` 线性映射，只额外加入共享周期模板，这说明该简单模板在本轮没有提供明确的独立收益。
- A5 约 25K–28K 参数，明显小于 A2（约 72K–519K）。容量不足可能解释部分退化，因此本轮否定的是“当前小型 ICPT 配置可直接替换 NLinear”，不是对所有跨周期 Transformer 的普遍否定。
- Stage B/C/D 均未运行：没有冻结任何位置编码，没有读取正式 test，也没有三 seed、Golden、样本级或注意力消融结果。因此本实验不能评价十种 PE 的优劣，也不能声明 ICPT 超过 Golden。

本次整理依据提交 `b817b53` 写入报告的汇总值。原始生成物约定位置为 `research_runs/phaseformer_icpt_pe_screen/`，但该目录不纳入 Git，当前检出中不存在，因此无法从 run-level CSV 独立重算；这不改变上述预注册门槛判断，但属于审计边界。

## 4. 最终结论

当前 ICPT 主路线应按计划停止：它在 ETTh2-720 上有局部潜力，但在 ETTm2、Electricity 和 Weather 上出现 7%–28% 的明显回退，不能稳定替换 NLinear，更不能作为超过 Golden 的新机制。位置编码尚未被测试，不能把本轮失败归因于某一种 PE，也不能从本轮选出最佳 PE。

若未来重启，应建立新的实验编号，先针对基础 residual backbone 做容量匹配、多周期或自适应周期、以及更合适的未来 query/decoder 设计，再重新通过同一 Stage A 门槛；在此之前保留现有 RCRF-NLinear，不更新默认 preset。
