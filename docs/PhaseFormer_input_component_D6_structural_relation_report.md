## 1. 扰动与质量边界

|条件|保留|破坏|
|---|---|---|
|cycle-order-reverse|每个 phase 的值集合、每个周期内部波形、最后周期|前29个周期的时间顺序|
|phase-desync|每个 phase 在前29周期的完整值集合、最后周期|同一周期内不同 phase 的共同演化/连续关系|
|adjacent-pair-swap|每周期值集合、均值、幅度、最后周期|前29周期相邻 phase-slot 的边|

三种扰动均严格保持最后一个输入点（QC最大绝对差为0）。它们不是加性删除，因此结果只能说明模型对
相应**关系**的即时敏感性，不可称为对某个数值成分 A 的因果依赖。

## 3. 解释与决策

1. **跨周期顺序和跨 phase 同步是所有模型共同且强的结构信息。** 原版并非不使用：两个扰动分别令
   M0 变差70.33%和61.71%。M1/M2整体损失稍小，符合此前“增强更能补偿”的现象；但其 NLinear branch
   同样显著受损，因此不能称增强分支只在使用被扰动关系以外的信息。
2. **相邻 phase-slot 的局部两两交换不是目标关系。** 原版只有+0.77%，增强整体和NLinear branch更接近
   零；方向不是“原版未用、增强在用”。
3. D6 与 D1--D5 合在一起，排除了目前已测试的数值成分、近期窗口、跨周期轨迹、跨周期排序、跨 phase
   同步和简单相邻关系。因而不应在这些同一候选上追加高耗时训练。

下一步若继续，应从“输入关系扰动”转向**模型内部表示诊断**：在相同 full 输入上，直接量化 phase
path 与 NLinear path 对预测残差的互补性，并用受约束的交换/投影只替换一个路径的可用信息。这样能先
找到“残差由哪类信息解释”，再构造新的候选输入关系，而非继续枚举删除操作。
