# 从相位—周期互补到完整模型多锚点融合

## 基于时间外校准的 PhaseFormer 结构化软路由方法

> 论文草稿，2026-08-29。本文记录 M3（Multi-Anchor Structural Soft Router）的设计动机、
> 方法和当前实验结果。当前证据仅来自六个数据集、H96、30% 训练数据、单 seed 的
> validation 实验；尚未进行 H192、full-train、三 seed test 或 Golden 确认。因此本文只能
> 报告受限协议下的正向信号，不能宣称取得正式 SOTA。

## 摘要

基于相位的时间序列预测模型擅长描述周期内部的相位关系，但不同周期补偿结构具有明显的
数据集适用域：RCRF+NLinear 在 ETTm 上较强，RCRF+ICPT 在 Weather/Electricity 上更有
优势，Rolling TriAxis 则利用相位、轨迹与周期间证据获得另一组互补预测。已有集成尝试把
RCRF+NLinear 作为唯一安全锚点，但其相对三个完整模型的逐指标包络平均退化 1.05%，说明
“安全退回一个非全局最优模型”不能解决跨数据集稳定性问题。

本文提出 M3：一种基于时间外校准的完整模型多锚点软路由方法。M3 冻结三个已经训练好的
完整 PhaseFormer 变体，以样本、通道和未来 24 步周期为粒度，从编码器历史和三个锚点预测的
结构描述符中估计凸组合权重。为避免 stacking 泄漏，24% 训练截止点的影子锚点仅在其未见过
目标的 24%–30% 时间段上训练路由器；正式验证时再换入 30% 训练截止点的完整锚点。路由器
只有 498 个可训练参数，不读取数据集 ID、未来真实值或 decoder future value。

在 ETTh1、ETTh2、ETTm1、ETTm2、Weather 和 Electricity 的 H96 validation 上，M3 相对
A1/I0/R0 逐数据集、逐指标最优包络的 12 指标宏平均比值为 0.992072，即平均改善 0.79%，
其中 10/12 个指标优于包络。Weather 的 MSE/MAE 分别改善 2.18%/2.24%，Electricity 改善
1.21%/0.64%；但 ETTh1-MAE 退化 0.58%，ETTm1-MAE 退化 0.01%，未通过全部指标严格
改善的预注册门槛。硬选择消融全部弱于软路由，样本分析也显示路由权重与事后最优锚点并不
充分一致。当前结果说明多完整模型的凸组合能够利用相位—周期预测误差的互补性，但尚不能
证明模型已学会可靠、可解释的专家适用域。

**关键词：** 长期时间序列预测；PhaseFormer；相位建模；周期建模；多锚点融合；
out-of-fold calibration；mixture of experts

## 1. 引言

长期时间序列预测通常同时面对两个相互关联、但并不等价的问题：未来处于周期内部的什么
位置，以及一个周期到下一个周期如何演化。PhaseFormer 从相位视角重排时间序列，在相同相位
槽之间传播信息，因而天然适合建模“周期内位置”。然而，相位结构本身不能完整表示周期之间
的电平漂移、振幅变化、形状创新和长期轨迹。为补足这一缺口，已有实验依次引入了 NLinear、
ICPT 和三轴融合等周期/轨迹分支。

这些模型没有形成单一的全局胜者。A1（RCRF+NLinear）在 ETTm 数据上稳健；I0
（RCRF+ICPT）在完整三 seed test 中对 Weather/Electricity 表现突出；R0（Rolling TriAxis）
在当前低成本 validation 协议下成为 Weather/Electricity 的最强参考。其优势差异并非简单的
超参数噪声：三者分别强调线性全 horizon 外推、周期间 token 关系和滚动历史证据，具有不同
归纳偏置。

一个自然选择是集成这些建模视角，但集成并不自动带来更好的模型。前一版 Safe-Regret
TriAxis 以 A1 作为精确回退点，相对 A1 平均改善 0.37%，相对 A1/I0/R0 逐指标包络却平均
退化 1.05%。问题在于安全目标本身错位：当 I0 或 R0 更强时，退回 A1 仍然是失败。另一方面，
直接用一个小网络硬选专家也可能把不确定偏好放大为错误的 one-hot 决策。

基于上述证据，本文研究如下问题：

> 能否把不同相位—周期建模方式产生的完整预测都作为安全锚点，在不读取未来真实值的条件下，
> 学习样本×通道×未来周期级的互补组合，并稳定超过三个锚点的原始包络？

本文的主要贡献可概括为：

1. 提出完整模型多锚点视角。与在单一 PhaseFormer 内部混合原子分支不同，M3 直接融合三个
   各自完整训练、具有不同周期归纳偏置的模型，从而把安全集合从单 A1 扩展为 A1/I0/R0。
2. 提出时间外影子锚点校准。路由监督来自影子锚点训练截止点之后的目标，避免让元路由器在
   锚点已经拟合过的训练目标上学习 stacking 规则。
3. 提出结构化周期级软路由。路由同时读取历史相位/漂移证据和锚点预测几何，并在每个未来
   24 步周期内保持同一组凸权重，在稳定性与细粒度适应之间取得折中。
4. 给出包含硬选择、regret 保护和软融合的受控消融。结果表明正向收益来自 soft convex
   fusion，而非可靠的 hard expert identification；这一结论由 1,121,992 个 validation
   样本×通道的误差回放进一步支持。

## 2. 背景与设计动机

### 2.1 三个互补锚点

给定长度为 720 的多变量历史序列，三个锚点均输出长度为 H 的预测：

- **A1：RCRF+NLinear。** PhaseFormer 主分支负责相位关系，NLinear 残差分支提供直接的
  全 horizon 线性外推；RCRF 根据相位可靠度调节两者的融合强度。
- **I0：RCRF+ICPT。** 用 inter-cycle patch transformer 替换 NLinear，显式建模周期 token
  之间的关系，更适合跨周期形状具有可迁移结构的数据。
- **R0：Rolling TriAxis。** 联合相位、局部轨迹和周期间预测，并利用多个历史滚动起点构造
  路由证据，强调历史上可验证的专家相对可靠性。

三者共享“相位主干 + 周期补偿”的总体叙事，但周期补偿的归纳偏置不同。M3 的设计动机不是
再次增加第四个预测分支，而是利用这些完整模型已经形成的、可观测的预测分歧。

### 2.2 为什么单锚点和硬选择不足

单 A1 安全锚点只保证候选不会任意偏离 A1，却不保证不会落后于 I0/R0。要对原始模型包络
不后悔，至少需要把包络中的所有候选纳入动作集合。

硬选择也存在两个问题。第一，三个锚点在很多样本上的误差接近，有限校准数据不足以可靠
估计 argmin；第二，即使任何单一锚点都不是最优，预测误差方向不同仍可能使凸组合更接近
真实值。由此，M3 选择 soft routing 作为正式模型，并把 hard routing 作为检验路由可识别性的
消融。

### 2.3 为什么需要时间外校准

若使用锚点训练阶段已经见过的目标训练路由器，某个锚点的训练内误差可能被系统性低估，
路由器会学习锚点的拟合能力而非泛化能力。M3 采用按时间顺序的 holdout：影子锚点只训练到
24% 截止点，路由器只使用预测起点不早于该截止点的 24%–30% 窗口。该段目标对影子锚点是
时间外的，而验证集仍与路由训练段分离。

## 3. 方法

### 3.1 问题定义

设编码器输入为

\[
\mathbf{X}\in\mathbb{R}^{B\times L\times C},
\]

其中批量大小为 \(B\)、输入长度 \(L=720\)、通道数为 \(C\)。三个冻结锚点分别产生

\[
\widehat{\mathbf{Y}}^{(k)}=F_k(\mathbf{X})
\in\mathbb{R}^{B\times H\times C},\quad
k\in\{A1,I0,R0\}.
\]

H96 被划分为 \(Q=H/P=4\) 个未来周期，周期长度固定为 \(P=24\)。M3 为每个样本 \(b\)、
通道 \(c\) 和未来周期 \(q\) 预测三维权重

\[
\mathbf{w}_{b,c,q}\in\Delta^2,
\]

并在该周期内复用同一权重。最终预测为

\[
\widehat{Y}_{b,t,c}
=\sum_{k=1}^{3}w_{b,c,q(t),k}\widehat{Y}^{(k)}_{b,t,c}.
\]

权重非负且和为 1，因此 M3 的输出始终位于三个完整预测的逐点凸包内。

### 3.2 历史结构描述符

对每个样本和通道，以历史标准差 \(s\) 归一化，提取四个只依赖 encoder history 的描述符：

1. 最近两个周期均值的有符号漂移；
2. lag-24 自相关；
3. 一阶差分波动率；
4. 相位可靠度，即跨周期相同槽均值的方差占历史总方差的比例。

它们分别描述近期电平变化、短周期重复性、局部粗糙度和相位槽结构强度。所有特征均裁剪到
\([-10,10]\)，降低极端小尺度通道对路由器的影响。

### 3.3 锚点预测描述符

对每个锚点和未来周期，提取四个部署时已经可用的预测形态特征：

1. 周期预测均值相对历史最后值的位移；
2. 周期内部相邻预测的平均绝对差，即粗糙度；
3. 该锚点相对三锚点逐时刻共识预测的平均分歧；
4. 周期终点与起点之差，即预测斜率。

三个锚点共形成 12 维预测描述符；与 4 维历史描述符合并后，得到
\(\mathbf{f}_{b,c,q}\in\mathbb{R}^{16}\)。这里使用锚点预测并不构成未来信息泄漏：这些预测
是推理阶段模型自身产生的结果，不包含 future truth 或 decoder future value。

### 3.4 结构化软路由

路由器是一个 16→24→3 的两层 MLP，并加入全局锚点偏置和未来周期偏置：

\[
\mathbf{z}_{b,c,q}
=\mathbf{b}_{\mathrm{global}}
+\operatorname{MLP}(\mathbf{f}_{b,c,q})
+\mathbf{b}_{q}.
\]

M3 使用温度 \(\tau=0.2\) 的 softmax：

\[
\mathbf{w}_{b,c,q}=\operatorname{softmax}
\left(\mathbf{z}_{b,c,q}/\tau\right).
\]

MLP 输出层和周期偏置以 0 初始化；全局偏置按温度校准，使初始实际权重为
A1/I0/R0=0.98/0.01/0.01。整个路由器只有 498 个可训练参数，三个影子锚点和三个正式锚点
始终冻结并保持 evaluation mode。

### 3.5 时间外影子锚点训练

每个 dataset×horizon 使用两个锚点组：

1. **影子锚点** \(F_k^{24}\)：只使用训练时间轴前 24%，最多训练 8 epoch；
2. **正式锚点** \(F_k^{30}\)：使用前 30%，最多训练 8 epoch。

路由器训练时调用 \(F_k^{24}\)，且校准窗口的第一个预测时刻不早于 24% 截止点；验证时调用
\(F_k^{30}\)。两组模型结构完全一致，区别只有时间截止点。端到端审计中 future-target
overlap count 为 0。

### 3.6 训练目标

对每个未来周期计算三个影子锚点的 MSE：

\[
e_{b,c,q,k}=\frac{1}{P}\sum_{t\in q}
\left(\widehat{Y}^{(k)}_{b,t,c}-Y_{b,t,c}\right)^2.
\]

令 \(e_{\min}=\min_k e_k\)，构造相对 oracle error

\[
r_k=\frac{e_k-e_{\min}}{\max(e_{\min},\epsilon)},
\]

并以温度 \(\tau_o=0.1\) 得到软路由监督

\[
p_k^*=\operatorname{softmax}(-r_k/\tau_o).
\]

M3 的训练目标为预测 Huber loss 与周期路由交叉熵之和：

\[
\mathcal{L}_{M3}
=\mathcal{L}_{\mathrm{Huber}}(\widehat{\mathbf{Y}},\mathbf{Y})
+0.1\,\mathcal{L}_{\mathrm{CE}}(\mathbf{p}^*,\mathbf{w}).
\]

M3 不使用额外的 mean-regret 或 CVaR 项；这些约束只出现在 M2 硬路由消融中。

## 4. 实验设计

### 4.1 数据集与协议

当前实验覆盖 ETTh1、ETTh2、ETTm1、ETTm2、Weather、Electricity。所有 setting 使用
L720、H96、P24、seed 2021 和 Huber loss。影子锚点训练比例为 24%，正式锚点为 30%，锚点
最多训练 8 epoch，路由器在 24%–30% 校准段最多训练 20 epoch；模型 checkpoint 按最低
validation loss 选择。ETT batch size 为 256，Weather/Electricity 为 64；学习率除
Electricity 为 0.002 外均为 0.001。

本实验的目标是筛选机制，而不是形成最终论文 benchmark。所有模型只在同一受限 validation
协议内比较，没有读取 test，也没有把本轮 validation 数值与固定 Golden test 数值混合比较。

### 4.2 对照与消融

- **M0 Global Hard：** 只学习三个锚点的全局先验，forward 选择单一完整锚点。
- **M1 Structural Hard：** 使用 16 维结构特征，并以 straight-through one-hot 进行周期级
  硬选择。
- **M2 Guarded Hard：** 在 M1 上加入相对三锚点 oracle envelope 的正 regret 均值和最差
  10% CVaR 约束。
- **M3 Structural Soft：** 与 M1 使用相同特征和容量，但保留 soft convex 权重。

评价参考是 A1/I0/R0 在每个 dataset×metric 上的最小值，即比任何固定单一锚点更严格的
逐指标包络。对每个候选报告 12 个比值的宏平均、最差比值以及是否全部小于 1。

### 4.3 预注册门槛

Pilot 在 ETTh1、ETTm2、Weather-H96 上执行，宏比值小于 1.01 且最差比值小于 1.03 才晋级。
补齐六数据集 H96 后，要求全部 12 个指标严格优于包络且宏比值不大于 0.995，才允许进入
H192。最终 24 指标全部改善后，才允许进行 full-train、多 seed test 和 Golden 比较。

## 5. 实验结果

### 5.1 消融结果

| 排名 | 方法 | 12 指标宏平均比 | 最差比值 | 全部优于包络 |
|---:|---|---:|---:|---|
| 1 | M3 Structural Soft | **0.992072** | **1.005759** | 否 |
| 2 | M0 Global Hard | 1.000881 | 1.010575 | 否 |
| 3 | M2 Guarded Hard | 1.003836 | 1.020964 | 否 |
| 4 | M1 Structural Hard | 1.005283 | 1.021797 | 否 |

M0 基本复现每个 setting 的强全局锚点，但不能产生新的收益。加入结构特征后，M1/M2 的
hard argmax 反而放大了错误选择；mean-regret/CVaR 没有修复这一问题。只有 M3 的连续权重
将宏平均降到 1 以下，支持“凸组合误差抵消”而不支持“当前特征已足以准确识别单一专家”。

### 5.2 与三个完整锚点的比较

| 数据集 | A1 MSE/MAE | I0 MSE/MAE | R0 MSE/MAE | M3 MSE/MAE | 相对逐指标包络变化 |
|---|---|---|---|---|---|
| ETTh1 | 0.710374/0.588060 | **0.693317/0.570566** | 0.697305/0.580682 | **0.683372**/0.573852 | -1.43% / +0.58% |
| ETTh2 | **0.211136**/0.322032 | 0.229856/0.339966 | 0.212106/**0.318662** | **0.207061/0.318130** | -1.93% / -0.17% |
| ETTm1 | **0.419504/0.433450** | 0.554277/0.520754 | 0.421400/0.440329 | **0.419063**/0.433507 | -0.11% / +0.01% |
| ETTm2 | **0.119617/0.235593** | 0.140011/0.258591 | 0.122749/0.238935 | **0.119488/0.235377** | -0.11% / -0.09% |
| Weather | 0.418749/0.293928 | 0.405543/0.299233 | **0.395253/0.286409** | **0.386628/0.280000** | -2.18% / -2.24% |
| Electricity | 0.114288/0.209123 | 0.114085/0.206621 | **0.110991/0.202801** | **0.109648/0.201510** | -1.21% / -0.64% |

M3 在 10/12 个指标上优于原始包络，收益主要出现在 Weather、ETTh2 和 Electricity。
ETTh1 的 MSE 明显改善，但 MAE 退化 0.58%，表明 soft 融合减少了少量大误差，却增加了更

因此 Stage A 在 H96 停止，未运行 H192 或 test。

## 6. 路由行为与样本级分析

### 6.1 样本误差分布

以每个 setting 中 MSE/MAE 联合最强的单一完整锚点作为样本分析 baseline，共回放
1,121,992 个 sample×channel：

| 分组规则 | 数量 | 占比 | 漂移均值 | lag-24 均值 | 差分波动 | 路由熵 |
|---|---:|---:|---:|---:|---:|---:|
| 显著改善：相对 MSE ≤ -10% | 159,789 | 14.24% | 0.0075 | 0.7616 | 0.3857 | 1.0514 |
| 相近：-10% < 相对 MSE < 10% | 847,863 | 75.57% | -0.0035 | 0.7169 | 0.4729 | 0.9314 |
| 显著退化：相对 MSE ≥ 10% | 114,340 | 10.19% | -0.0007 | 0.6861 | 0.3769 | 1.0270 |

改善组比退化组具有更高的 lag-24 相关（0.7616 vs 0.6861），并具有更高的路由熵。这一现象
与“周期结构较清晰时多个周期归纳偏置可以互补”的解释一致，但只是观察性相关，不能证明
lag-24 或周期性导致了收益。较高路由熵也说明显著改善并不依赖某个接近 one-hot 的锚点，
而可能来自多个预测的共同作用。

### 6.2 平均权重与事后 oracle

| 数据集 | A1 权重 | I0 权重 | R0 权重 | A1 oracle | I0 oracle | R0 oracle |
|---|---:|---:|---:|---:|---:|---:|
| ETTh1 | 0.702 | 0.149 | 0.149 | 0.322 | 0.404 | 0.274 |
| ETTh2 | 0.737 | 0.130 | 0.132 | 0.393 | 0.219 | 0.388 |
| ETTm1 | 0.970 | 0.015 | 0.015 | 0.450 | 0.259 | 0.291 |
| ETTm2 | 0.860 | 0.069 | 0.071 | 0.433 | 0.260 | 0.308 |
| Weather | 0.323 | 0.371 | 0.306 | 0.358 | 0.315 | 0.326 |
| Electricity | 0.297 | 0.291 | 0.411 | 0.311 | 0.317 | 0.372 |

ETT 上 M3 整体偏向 A1，Weather 的三个权重接近均衡，Electricity 更偏向 R0。这与三个模型
的全局性能大体一致，但与逐样本、逐周期事后 oracle 的占比并不匹配。例如 ETTm1 中 A1
平均权重为 0.970，而 A1 只在 45.0% 的样本×通道×周期上取得最低 MSE。由于 soft 权重并非
在拟合 oracle 频率，不能把它解释为“模型认为 A1 有 97% 的获胜概率”；更准确的解释是，
A1 提供主要预测中心，I0/R0 提供小幅方向性修正。

这种不匹配同时解释了 hard 消融的失败：把偏向 A1 的连续权重取 argmax 会丢掉 I0/R0 的
小幅修正，却无法可靠找回它们真正获胜的样本。M3 当前更像一个结构条件化的 stacking
校准器，而不是已经学会专家适用域的 hard mixture-of-experts。

## 7. 讨论

### 7.1 相位与周期如何协同

三个锚点都保留 PhaseFormer 的相位主干，因此 M3 不是用一个完全无关的模型覆盖相位预测。
它组合的是三种“如何补全周期演化”的答案：NLinear 提供全 horizon 线性轨迹，ICPT 提供
周期间 token 交互，Rolling TriAxis 提供基于历史回测的相位/轨迹/周期证据。路由器观察近期
漂移、lag-24 结构和锚点未来形态后，决定这些周期补偿应以什么比例作用于当前样本。

从这一视角看，PhaseFormer 负责共享的相位坐标系，三个锚点提供不同的周期演化假设，M3
负责估计这些假设的局部可信度。Weather/Electricity 的较均衡权重和更明显收益说明，当单一
周期演化模型不足时，完整模型之间确实存在可利用的预测互补。

### 7.2 方法的新颖性边界

M3 的新意不在 softmax 或 stacking 本身，而在三个约束的组合：以不同相位—周期归纳偏置的
完整 PhaseFormer 为锚点、用时间外影子锚点构造无训练内目标重用的路由监督、并在
sample×channel×future-cycle 粒度上用历史和预测几何共同路由。它比数据集 ID 切换更统一，
也比只在单一模型内部混合原子分支拥有更强的安全集合。

但当前结果不足以支持“顶会级强模型已经完成”的结论。M3 本质上仍是三个完整模型的昂贵
ensemble，推理需要三次锚点前向；而且 shadow→full 的能力迁移没有理论保证。后续工作必须
证明该路由可跨 horizon、跨 seed 和完整训练规模泛化，并考虑蒸馏或共享主干，否则方法更接近
有效的研究诊断工具而非最终部署架构。

### 7.3 失败指标的启示

ETTh1-MAE 的退化是最重要的反例。M3 在该数据集把 MSE 从 0.693317 降到 0.683372，却把
MAE 从 0.570566 提高到 0.573852。这说明以 Huber prediction loss 和周期 MSE oracle 训练的
路由更偏向压制大误差，未同时保护平均绝对误差。一个合理假设是训练目标与双指标 gate 不
完全对齐，但当前实验没有验证改成 MAE oracle 或双目标约束是否有效，不能事后归因。

ETTm1 几乎完全回退 A1，同样暴露 shadow OOF 的局限：影子锚点在 24% 截止点的相对能力
可能与 30% 正式锚点不同，路由器学到的权重无法充分迁移。多折 rolling-origin OOF 可以同时
增加校准样本覆盖并估计这种迁移方差，是比扩大路由网络更直接的后续方向。

## 8. 局限性与下一步工作

本文当前存在以下限制：

1. **实验规模有限。** 只有 H96、30% train、seed 2021 validation；没有 H192、full-train、
   三 seed test 和固定 Golden 比较。
2. **validation 参与选择。** M3 是从 M0–M3 中按六数据集 validation 宏比值选出，结果是
   机制筛选证据，不是独立测试泛化估计。
3. **单段 OOF。** 路由只在一个连续 6% 时间段训练，可能覆盖不了完整季节和状态变化。
4. **shadow→full 偏移。** 24% 影子模型与 30% 正式模型的预测分布和相对排名可能变化。
5. **计算成本。** 推理需要保留三个完整锚点；498 个路由参数很小，但总计算量并不小。
6. **解释性有限。** soft 权重与真实 oracle 占比不一致，权重不能直接解释为专家获胜概率。
7. **尚未稳定支配。** ETTh1-MAE 和 ETTm1-MAE 未超过包络，预注册 gate 明确失败。

后续实验应按以下顺序推进：

1. 使用多个 rolling origins 生成多折时间外锚点预测，检验单段校准是否是主要瓶颈；
2. 显式校准 shadow 权重到 full-anchor 权重，例如基于锚点预测分布漂移的温度/收缩校准；
3. 在不改结构的前提下检验 MSE+MAE 双 oracle 或 Pareto regret，重点修复 ETTh1-MAE；
4. 只有六数据集 H96 全指标通过后，再冻结统一模型扩展 H192；
5. H96/H192 均通过后，才开展 full-train、三 seed test 和 Golden 对比；
6. 若正式效果成立，再研究共享 PhaseFormer 主干或将三锚点蒸馏为单模型，降低推理成本。

## 9. 结论

本文提出 M3，一种面向相位—周期互补的完整模型多锚点软路由方法。它通过时间外影子锚点
学习样本×通道×未来周期级的凸组合，在六数据集 H96 受限 validation 协议下相对
A1/I0/R0 逐指标包络平均改善 0.79%，并改善 10/12 个指标。这是相对此前单 A1 安全集成的
实质进展，也证明完整模型之间的预测互补可以被低容量路由器利用。

与此同时，两个 MAE 指标仍未改善，所有 hard 路由均失败，soft 权重也没有准确复现事后
oracle。因而当前最可靠的结论不是“M3 已成为全局最优模型”，而是：**多锚点安全集合与
时间外 soft calibration 是一条有正向信号的研究路线，但其收益目前来自凸组合误差抵消，
尚未形成跨 setting 稳定、可解释、经正式 test 验证的专家路由模型。**
