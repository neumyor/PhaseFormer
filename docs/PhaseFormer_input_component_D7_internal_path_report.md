# D7：内部路径诊断结果

ETTm1/L720/H192/seed2021，512个均匀 validation origins；完整输入、无训练、无 test。

目标不是寻找“原版完全没用”的输入，而是量化 NLinear path 在什么窗口中最能修正 phase path：每窗口目标为
`phase_MAE - fused_MAE`。六个输入描述量在看预测结果前固定；连续五折 OOF 仅用于候选发现。

|描述量与收益相关|M1 weak|M2 RCRF|
|---|---:|---:|
|近期差分|−0.076|−0.121|
|近期偏离|+0.233|+0.057|
|周期水平波动|**+0.490**|**+0.534**|
|周期幅度波动|+0.299|+0.336|
|最后周期水平偏移|**+0.483**|**+0.488**|
|日滞后变化|+0.139|+0.238|
|六特征连续5折 OOF R²|0.205|0.299|

另有两个内部一致性量：平均 `phase_MAE-fused_MAE` 为 M1=0.231、M2=0.355；NLinear correction 与 phase
residual 的余弦对齐均值为0.703/0.791。这说明它确实主要在朝 phase residual 的正确方向修正，而非随机
增加一个残差。

结论：最可复现的结构缺陷不应表述为“PhaseFormer不使用 cycle-level 信息”——D3/D4/D5 已证明原版会
使用。更准确的是：**当跨周期水平状态波动、尤其最后周期相对历史发生偏移时，phase path 的误差明显更
需要 NLinear-style 全时间轴校正。** 这为后续设计轻量状态校正头提供了机制动机，但还不是新模块有效性的
证明。完整低成本确认应优先比较一个只建模末值锚定周期水平状态的轻量校正头，与同参数量非结构化线性
控制，而不是继续枚举输入删除。
