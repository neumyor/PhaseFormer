# B0H+ 的趋势与周期成分：对照原版 PhaseFormer 与四个基线

（2026-10-30；数据来自 `~/niuyiming/component_mse_20261023`，表格由 `scripts/component_mse/b0hp.py --report` 生成后整理）

## 1. 目的与口径

- 目的：用既有的成分分解工具，量化 B0H+ 相对原版 PhaseFormer 和四个官方基线在趋势成分上的差异。
- 模型：原版 PhaseFormer（E14 协议）、B0H+（b0 臂，level 编码器读「周期均值 ‖ phase token 槽内均值」），
  以及 DLinear、SparseTSF、FITS、CycleNet。PhaseFormer-LA 不在本文档的对比范围内。
- 数据与协议：6 个数据集（Weather、Traffic、ETTh1、ETTh2、ETTm1、ETTm2）× 预测长度 {96, 192}，共 12 个 setting；
  3 个 seed（2021、2022、2023）；输入长度 720；误差在训练用的 StandardScaler 标准化空间。
- B0H+ 的配置取自 `docs/PhaseFormer_VLDBJ_b0hp_best_settings.csv`：seed 2021 复用产生该表数字的训练，
  seed 2022/2023 在同一配置上重训（配置固定、只变 seed）。配置本身是在 seed 2021 测试集上逐 setting 选出的，
  与其余行的"单次训练"口径不完全一致，引用时需注意。
- 基线与 PhaseFormer 的完整测试预测沿用 2026-10-26 的成分报告，训练协议见
  `docs/PhaseFormer_component_mse_report.md`。

## 2. 分解定义

对长度为 H 的预测窗口按周期 P=24 切成 H/P 个周期：

- `cycle-level`：每个周期内取均值，作为该周期的水平值，再按周期填回（分段常数趋势）。
- `folded`：把所有周期按相位对齐后取均值，得到平均周期形状，再平铺回整个窗口。
- 残差 = 预测 − 趋势，即周期成分。

`cycle-level` 与 `folded` 都是正交投影，所以趋势成分 MSE + 周期成分 MSE = 总 MSE，三者可以逐项对照。
B0H+、PhaseFormer 与基线的分解都在同一组真值上做，逐窗口对齐。

## 4. 读法

- 趋势成分（cycle-level，12 setting 平均）：PhaseFormer 0.1500，B0H+ 0.1465，降低 2.35%；
  最强的基线是 FITS（0.1510），B0H+ 比它低 3.00%。若逐 setting 取当时最好的基线（Oracle，平均 0.1502），
  B0H+ 低 2.48%。
- folded 定义下方向相同：PhaseFormer 0.1248、B0H+ 0.1192，降低 4.54%；相对最强的基线（FITS 0.1254）降低 4.95%。
- 逐 setting 的最低值分布：B0H+ 在 7/12 个 setting 上趋势误差最低。其余 5 个是：
  Weather-96、Weather-192、ETTh2-96 由 FITS 最低（分别低 1.2%、2.5%、0.7%），
  ETTh1-192、ETTm1-96 由原版 PhaseFormer 最低（分别低 0.2%、0.15%）。
  这 5 个差距都在 2.5% 以内，且都不影响聚合结论。
- 趋势优于原版 PhaseFormer 的 setting 有 10/12，例外是 ETTh1-192 与 ETTm1-96（差距 ≤0.2%）。
- Weather 是唯一基线总误差也能赢的格子：Weather-96 的总 MSE 仍是 B0H+ 更低（0.1440 对 FITS 0.1470），
  但 Weather-192 FITS 以 0.1871 略低于 B0H+ 的 0.1878（0.4%）。这一点在引用时不应略去。
- 周期成分与总误差同向：B0H+ 的周期成分比 PhaseFormer 低 2.15%，总 MSE 低 2.25%。
- 结论可以说：B0H+ 相对原版 PhaseFormer 的提升同时体现在趋势和周期两部分，趋势的提升不是靠牺牲周期换来的；
  相对四个基线，趋势成分平均低 2.5–3.0%，但 Weather（尤其 192）与 FITS 的差距很小，不能表述为全面领先。

## 5. 复现

```bash
# 1) 生成 B0H+ 三个 seed 的任务文件（seed 2021 复用已有 run，2022/2023 新建）
python3 scripts/component_mse/b0hp.py --prepare
# 2) 训练缺少的 seed（会跳过已有 result.json 的任务）
python3 scripts/component_mse/b0hp.py --run --gpus 0,1,2,3 --slots-per-gpu 2
# 3) 导出预测到成分 dump（每次导出都会断言导出 MSE 与记录值一致）
python3 scripts/component_mse/b0hp.py --export --skip-existing
# 4) 生成表格（本文档的表格由此命令输出整理）
python3 scripts/component_mse/b0hp.py --report \
    --models PhaseFormer,B0H+,DLinear,SparseTSF,FITS,CycleNet \
    --out docs/PhaseFormer_VLDBJ_trend_b0hp.md
```

- 预测与真值：`~/niuyiming/component_mse_20261023/predictions/`（`truth/`、`predictions/<model>/`、`results/`）。
- B0H+ 的 run 目录记录在 `docs/PhaseFormer_VLDBJ_b0hp_best_settings.csv` 的 `run` 列。
- 分解实现：`scripts/component_mse/trend_definitions.py`（`score_file`、`apply_trend`）。

## 6. 限制

- 单 seed 选配置 + 3 seed 报告：B0H+ 的配置在测试集上逐 setting 选过，趋势上的优势里包含选择偏差；
  b0 搜索的验证集选优相对测试最优平均损失 1.26%（最大 3.74%），因此 1% 量级的差距不宜过度解读。
- 基线用统一协议（Adam 1e-3、Huber、30 epoch、patience 8）训练，不是各自论文的配方，只能与本文内部互相比。
- 分解周期固定为 P=24；ETTm1 上模型周期可能是 48，但分解口径对所有模型一致，不影响横向比较。
