# PhaseFormer-D 设计说明（2026-11-11）

PhaseFormer-D 与 PhaseFormer-I 是后续主要测试的两个候选模型。实现：`scripts/biaxial/model.py` 的 `PhaseFormerD` / `DCfg`；测试：`tests/test_phaseformer_d.py`；任务：`python -m scripts.biaxial.configs D1`（ETTh1/ETTm1 × 4 个预测长度 × 3 种子，与 F1 同网格）。

## 结构

窗口先做实例归一化（与 I 相同），折成 X (K 周期 × P 相位)。两个分支各自预测对"最后一个周期"（锚点）的修正，并用各自归一化所用的统计量还原到公共单位；输出为 0 时精确退化为锚点。

| | 周期分支 | 相位分支 |
|---|---|---|
| 要建模的 | 每个相位随周期的演化（水平、漂移、慢变季节） | 一个周期内的形状 |
| 路由轴 | 周期轴（每个相位列各自对 k_t 个 token 路由） | 相位轴（每个周期行各自对 p_s 个 token 路由） |
| 输入归一化 | 去掉每相位的周期均值（季节轮廓），再除以每个窗口一个标量尺度（共享） | 每个周期按自己的相位均值与标准差归一化（只剩形状） |
| 为何这样归一化 | 轮廓归相位分支；逐相位除标准差会放大几乎不动的相位的噪声，所以只用一个共享尺度 | 水平与幅度不能进入形状分支；水平的变化只由周期分支负责 |
| 压缩 | K→k_t=8；P→p_t=P/4（动态平滑，相位分辨率可低） | K→k_s=4；P→p_s=P（形状需要完整相位分辨率，周期可以强压缩） |
| 输出还原 | ×该窗口的尺度 | 先减去每个预测周期的相位均值（只改形状不改水平），再乘最后一个周期的标准差 |

融合（`fusion='gate'`）：两个修正在公共单位下相加，再各乘一个依赖窗口的门 g = 2σ(Linear([log 尺度_t, log 尺度_s, 两分支池化特征]))，线性层零初始化，初始 g=1，即与直接相加完全相同；`fusion='sum'` 为直接相加。

方差下限 `t_eps`、`s_eps` 默认 1e-2（尺度下限约 0.1 个窗口标准差），LayerNorm 风格（`norm_t/norm_s`：post | pre，`embed_t/embed_s`：mlp_ln | lin_mlp）与傅里叶相位身份（`phase_id`）为可选项，默认与 PhaseFormer-I 的基线相同，待 F1 结果决定。

## 未验证项

分支压缩比、方差下限、门是否有收益、两个分支的归一化方式，均为按分支职责推理出的默认值，尚无对照实验。默认配置（ETTh1，P=24）：12,158 参数，1.34 MFLOPs/通道（PhaseFormer-I 约 2.5）。
