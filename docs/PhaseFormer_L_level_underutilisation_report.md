# 冻结 PhaseFormer 是否未充分利用水平信息？

> 实验编号：`level_underutilisation_v1`
> 执行日期：2026-09-24
> 代码：`scripts/probe_level_underutilisation.py`
> 产物：`research_runs/level_underutilisation_v1/`
> 性质：既有 checkpoint 的事后探针；不训练、不改 checkpoint；拟合只用 train，超参只用 val，**test 只用于最终评估**

## 0. 结论摘要

**这个实验没有支持"原模型未能充分利用水平信息"这一较强主张。** 直接检验的结果是负面的：

1. **水平信息不能在样本外预测冻结模型的误差。** 用训练集拟合"跨周期水平轨迹 → 尺度无关的逐窗口误差"，在 test 上的排序相关均值仅 **−0.054**（60 个 cell 中 46 个为负），而 R² 远小于 0（比直接预测均值还差）。
2. **关键对照证明这不是拟合噪声，而是没有信号**：把每个窗口的时间轴打乱后再取同样的周期均值（`time_shuffled_level`），得到的相关是 **−0.057**——与真实水平轨迹几乎完全一致。也就是说，这一点点相关性来自数值的边缘分布，**不来自水平轨迹本身**。
3. **训练得到的修正确实有用，但其收益与水平波动的关联很弱**：逐窗口增益为正的有 40/60 个 cell，而 ρ(跨周期水平标准差, 增益) 均值为 **+0.094**（60 个中 43 个为正，最大 +0.446）。

因此可以写进论文的是**较弱且已有证据支持**的表述：

> 加入时间轴修正能在多数 setting 上降低融合误差，且收益在跨周期水平波动较大的窗口上略强；但**没有证据表明原模型"看到了水平信息却没有用上"**——水平信息在样本外并不能预测原模型的误差。

这**阻断**了"原模型未充分利用水平变化"这一较强表述。原模型的误差在这 5 个数据集上不是水平可预测的。

## 1. 为什么需要这个实验

既有证据只能支持较弱的说法：

- E14 配对比较显示，在 ETTh2/ETTm2/Weather 的 12 个 setting 上，加入 temporal branch 后双指标优于配对原模型；
- 样本级诊断（`docs/PhaseFormer_input_component_D7_internal_path_report.md`）发现跨周期水平波动、尤其末周期相对历史偏移时，phase path 的误差更需要全时间轴修正（该报告报出 +0.49/+0.48 的相关）。

但原模型本身也使用水平信息（D3/D4/D5 已证明），所以不能说它"看不到"这部分信息。要主张"使用了但未充分利用"，需要一个**直接**的检验：如果水平信息能够稳定预测冻结模型的误差，且收益集中在预期窗口，才支持该主张。

## 2. 设计

对 5 个数据集（ETTh1、ETTh2、ETTm1、ETTm2、Weather）× 4 个 horizon × 3 个 seed = **60 个 cell**，冻结各自的 `phase_only`（`scheme_name = no_residual`）checkpoint。

**水平轨迹**：把 720 步回看窗口按数据集物理周期（ETTh1/ETTh2/Weather = 24 步，ETTm1/ETTm2 = 96 步）切成最近 K 个不重叠周期，取每周期均值，得到 (K, C) 的轨迹；K = 720 // period（即 30 或 7）。特征为该轨迹加一个截距。

**Part A：水平信息能否样本外预测冻结模型的误差？**
在 train 上拟合 ridge（特征标准化后，惩罚在 val 上选），目标是**尺度无关的逐窗口误差**——即 `(y − ŷ_φ)` 除以该通道在 train 上的窗口标准差中位数后逐元素平方的平均。用中位数而不是逐窗口 σ：近似常数窗口的 σ ≈ 3e-3，逐窗口相除会把目标放大到 1e3。

在 test 上报告预测值与真实误差的**排序相关**与 R²。

**Part B：训练得到的修正，其收益是否集中在水平波动大的窗口？**
取同 setting、同 seed 的配对 `l_main`（dense PhaseFormer-L）checkpoint，在**同一批 test 窗口**上运行，逐窗口增益 = phase 误差² − 融合误差²，按三个水平统计量分四等分报告。

**对照（参数个数相同、语义不同）**：
| 对照 | 构造 |
|---|---|
| `shuffled_level` | 训练集特征跨窗口随机置换（只置换特征，不置换目标——两者同序置换对最小二乘是恒等变换） |
| `time_shuffled_level` | 先把每个窗口的时间轴随机置换，再取同样的周期均值：数值分布不变，轨迹被破坏 |
| `random_projection` | 固定随机投影到 K 维 |
| `pca_matched` | 归一化窗口协方差的前 K 个主轴（train 上估计） |

## 3. 质量检查

冻结模型的复现：本探针重算的 `phase_only` test MSE 与 E14 记录的 `test_mse` 一致，**最大差 1.9e-05，均值 2.1e-06**（60 个 cell）。

## 4. 结果

### 4.1 Part A：水平轨迹对冻结模型误差的样本外预测

| 特征 | ρ 均值 | ρ 范围 | ρ > 0 的 cell | R² 均值 |
|---|---:|---:|---:|---:|
| **水平轨迹** | **−0.054** | [−0.137, +0.109] | 14/60 | ≪0 |
| 时间打乱的周期均值（对照） | −0.057 | [−0.142, +0.115] | 15/60 | ≪0 |
| 跨窗口置换（对照） | +0.006 | [−0.087, +0.126] | 35/60 | ≪0 |
| 随机投影（对照） | −0.008 | [−0.094, +0.093] | 23/60 | ≪0 |
| 窗口 PCA（对照） | −0.005 | [−0.094, +0.128] | 27/60 | ≪0 |

按数据集（仅水平轨迹）：

| 数据集 | ρ 均值 |
|---|---:|
| ETTh1 | −0.052 |
| ETTh2 | −0.097 |
| ETTm1 | **+0.039** |
| ETTm2 | −0.057 |
| Weather | −0.101 |

**读法**：真实水平轨迹与"时间打乱后同样的周期均值"给出几乎相同的相关（−0.054 对 −0.057），而后者已经破坏了轨迹结构。因此这 −0.05 量级的相关来自数值的边缘分布，而不是水平随时间如何变化。R² 远小于 0 意味着该预测连"直接预测均值"都不如。**水平信息在这 5 个数据集上不能样本外预测冻结模型的误差。**

### 4.2 Part B：训练修正的收益与水平波动

| 水平统计量 | ρ(统计量, 逐窗口增益) 均值 | 范围 | ρ > 0 的 cell |
|---|---:|---:|---:|
| 跨周期水平标准差 | **+0.094** | [−0.150, +0.446] | 43/60 |
| 末周期相对历史偏移 | +0.051 | [−0.139, +0.325] | 41/60 |
| 周期首末水平差 | +0.038 | [−0.221, +0.249] | 39/60 |

逐窗口增益本身：均值 **+0.003411**，为正的有 **40/60** 个 cell。

分位数（跨 cell 汇总，`level_std`）：Q1 +0.0044、Q2 +0.0016、Q3 +0.0122、Q4 +0.0142——方向为正但**不单调**（Q2 低于 Q1）。

**读法**：训练得到的修正确实在多数 cell 上降低误差；其收益与跨周期水平波动的关联方向为正但很弱（+0.09，最大 +0.45），远低于 D7 在同一问题上报出的 +0.49。D7 用的是 ETTm1-192、512 个均匀 validation origin 与连续五折 OOF 候选发现，协议与本实验不同，两者不能直接比较。

## 5. 应当如何表述

**可以写**：

> 逐窗口证据表明，加入时间轴修正在多数 setting 上降低融合误差，且收益在跨周期水平波动较大的窗口上略强（ρ ≈ +0.09）。

**不能写**：

> 原模型使用了水平信息但未能充分利用它。（本实验直接检验该主张，结果不支持：水平信息在样本外不能预测冻结模型的误差。）

**也不能写**：

> 原模型看不到水平信息。（D3/D4/D5 已证明它会使用。）

## 6. 局限

1. **checkpoint 不是盲测的**。这些 `phase_only` / `l_main` checkpoint 来自曾受 test 表现影响的配置搜索，因此本实验的 test 评估是**条件性证据**，不是无偏泛化估计。本探针自身没有用 test 做任何选择（拟合只用 train、惩罚只用 val），但 checkpoint 层面的暴露无法消除。
2. **Part A 依赖于一种修正形式**。更早的一版把水平特征映射到**整个误差向量**并作为修正施加；该映射只有 `horizon × (cycles + 1)` 个参数，在任何惩罚下都无法超过空操作（诊断见 `scripts/_probe_level_diag2.py` 的记录），所以它衡量的是修正形式的容量，不是模型对水平信息的使用。本报告采用的是预测误差**标量**的形式，统计功效高得多，但仍然是线性、跨通道共享、只读取周期均值的。
3. **水平轨迹的定义是周期均值**。ETTm1/ETTm2 的 720 步回看只能容纳 7 个整周期（余下 48 步未用）；更细或更粗的水平定义可能给出不同结果。
4. **只覆盖 5 个数据集**（ETTh1/ETTh2/ETTm1/ETTm2/Weather）。Electricity 与 Traffic 因通道数与探索性定位未纳入。
5. **Part B 的相关是逐窗口关联**，不是因果；且同一数据集内 4 个 horizon 共享数据性质，60 个 cell 不构成 60 个独立数据集。
