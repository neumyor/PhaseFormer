# PhaseFormer-LA 去掉 amplitude 通路的消融（2026-10-27）

在 `docs/PhaseFormer_VLDBJ_best_known_vs_golden.md` 记录的那 28 个最佳 setting 上，
用同一组参数训练去掉 amplitude 通路的变体，与完整 PhaseFormer-LA 逐 setting 对比。

## 1. 消融对象

LA（`vldbj_m1` 的 `m1` 臂）有三条通路：phase 通路（backbone 的相位表示）、level 通路
（`lowrank_head`，把周期均值写到三个 horizon 剖面上）、amplitude 通路。amplitude 通路就是
`IsolatedBranch.communication`：

```
write = output(source(trend))                 # trend = level 分支状态，width 2–4
delta = (phase - phase.mean(-2)) * write      # 按相位槽居中
phase = phase + delta
```

它用 level 状态生成一个缩放因子，作用在相位表示上，居中保证未来每个周期的均值不变——即
正文里"由 level 计算出的 amplitude token 缩放 shape、同时保持周期均值"那一项。
去掉它对应 `b0` 臂：phase 通路和 level 通路都在，只少这一个模块。

规模：modulation 只有 14–70 个参数（ETTh1 14、Weather/Electricity 22、Traffic 70），
占总量 0.4%–1.3%。

## 2. 口径

- 每个 setting 沿用其最佳配置：周期长度、gate_init、扩展学习率倍数、communication width、
  backbone 学习率倍数、level head（S1/S2/S3）、门控共享方式都相同。
- 唯一改动是 `arm: m1 -> b0`。
- seed 2021；LA 的对照数**取自同名 run、同 seed、同一个 best-validation checkpoint 读取**，
  与 b0 构成逐 setting 的配对。6 个 setting 的最佳表数字来自另外两个 seed（表里取三 seed 最优），
  这里换成 seed 2021 的配对值，差异 0.1%–0.9%。
- 初始化已校验：28 个 setting 上 b0 与 m1 的公共参数逐位相同，b0 只缺少
  `lowrank_interaction_branch.communication.*` 的两个张量。
- 全部为单 seed，无误差棒；配置本身是测试集选优，属条件性结果。

## 6. static-q 替换（另一套协议，三 seed）

static-q 保留槽内居中的调制形式 $\Delta Z_l=(Z_l-\bar Z)\odot q_c$，把 $q_c=W_2W_1z$ 换成逐通道自由参数，参数量由 $2(k+D)$ 变为 $C\cdot D$。它检验"调制向量必须由 level 状态驱动"是否必要。这一线在 `~/niuyiming/PhaseFormer_vldbj_supp_20261013/research_runs/vldbj_staticq/`，注册协议配置（gate 0.2、扩展学习率 1.0、width 2），seed 2021–2023 均值，基线是同协议的 PhaseFormer-LA。

结论：static-q 与完整 LA 的差距在 0.2%–1% 量级，远小于去掉分支的 0.80% 平均退化。槽内居中加逐通道缩放这一结构本身承担了主要收益，由 level 状态驱动 q 是更小的增量。

## 7. 结论

1. **amplitude 通路是净增益，但幅度不大**：28 个 setting 中 21 个 MSE 变差，去掉后七数据集
   平均 MSE +0.80%、MAE +0.41%。MAE 在 22/28 个 setting 变差。
2. **贡献集中在 ETTh1 与 ETTm1**：ETTh1 平均 +1.45%、ETTm1 平均 +2.06%，单点最大为
   ETTh1-192（+4.40%）与 ETTm1-336（+4.13%）。这两个数据集周期波动占总误差比例小
   （24%–56%），level 漂移相对重要，而 amplitude 正是挂在 level 状态上的缩放项。
3. **ETTm2 与 Weather 上基本无效**：ETTm2 四个 horizon 的 ΔMSE 都在 ±0.08% 内，平均 +0.01%；
   Weather 平均 +0.19%，但 MAE 反而 −0.13%（Weather-96 的 MAE 去掉后好 1.21%）。
4. **去掉后反而更好的 7 个 setting 幅度都很小**（−0.01% 到 −0.55%），其中 ETTh1-720 的
   −0.55% 是唯一个超过 0.2% 的。这说明该通路在这些 setting 上与 level 通路存在冗余，
   而不是有害。
5. **MSE 的 Δ 普遍大于 MAE 的 Δ**（平均 0.80% 对 0.41%），说明这条通路主要压低少数大误差
   窗口，而不是整体平移预测。
6. 与成分分析结论一致：LA 对趋势成分的修补主要来自 level 通路，amplitude 通路提供的是
   level 与 shape 之间的耦合，其增益依赖于该数据集上 level 与 amplitude 是否真的耦合。
