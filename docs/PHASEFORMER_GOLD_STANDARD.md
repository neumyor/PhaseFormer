# PhaseFormer 原始结果金标准

## 1. 用途与权威性

本文件记录用户于 2026-08-11 提供的论文 Table 5 截图中，原始
PhaseFormer 在各数据集和预测长度上的正式结果。自本文件建立后，所有
PhaseFormer 改进实验的最终提升声明都必须以本表中相同
`dataset × horizon` 的结果为金标准，不得用某次重新训练结果静默替换。

重新训练的 original baseline 可以用于排查实现、环境、随机种子或评估协议差异，
但必须标记为“matched rerun”，不能改变本文件中的金标准数值。若实验设置与本表
不一致，则只能报告实验内的配对比较，不得声称相对本金标准获得可直接比较的提升。

## 2. 评估口径

- 模型：原始 PhaseFormer。
- 输入长度（lookback / `seq_len`）：720。
- 预测长度（horizon / `pred_len`）：96、192、336、720。
- 指标：MSE、MAE，均为越低越好。
- 精度：按来源表格保留三位小数。
- 来源表格的模型子列顺序为 **MSE、MAE**。虽然图片说明文字先写 MAE 再写
  MSE，本文件严格按照实际表头读取，避免指标互换。
- 当前截图覆盖 7 个数据集、28 个任务。仓库支持的 Exchange 数据集没有出现在
  截图中，因此 Exchange 暂无本文件认可的金标准，不得推测或补造。

## 4. 后续实验的比较规则

对于新实验结果 `new_metric` 和本表对应的 `gold_metric`，统一计算：

```text
绝对变化 = new_metric - gold_metric
相对改善率(%) = (gold_metric - new_metric) / gold_metric × 100
```

相对改善率为正表示提升，为负表示退化。每个正式结果必须同时报告：

1. 数据集、horizon 和 `seq_len`；
2. 新实验的 MSE、MAE；
3. 相对金标准的 MSE、MAE 绝对变化和相对改善率；
4. seed 数量及均值、标准差；
5. 数据划分、预处理、指标实现和测试协议是否与原始结果一致；
6. 若仅一个指标改善，明确写为“单指标改善”，不得表述为全面提升。

默认只有 MSE 和 MAE 都低于对应金标准时，才能称为“双指标提升”。由于金标准只保留
三位小数，差异非常小时还应结合多 seed 方差判断，不能把舍入误差当成稳定收益。

## 5. 更新规则

本文件是固定参照，不因普通实验重跑而更新。只有用户提供更权威的原始论文表格、
官方结果文件，或明确要求修订金标准时才能修改。任何修改都必须记录来源、原因、
旧值和新值，并经过人工复核。
