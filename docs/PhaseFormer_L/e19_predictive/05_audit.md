## 2. 审校发现的实质结论

1. **只有 `τ̂` 具备判别力**：另两个候选在已知符号的数据集上**顺序相反**（ETTm1 高于 ETTm2），
   因此 §4.7 若用 `cycle_level_std` 做阈值将得到系统性错误。这一点必须写进 §4.7 表注——
   否则读者会以为三个统计量等价。
2. **Electricity 落在可分离区间内部**（τ̂ = 54.46 ∈ (51.11, 63.58)），其诊断判定对 `ν*` 位置敏感；
   且实测其修正器相对 matched `phase_only` 为 **+3.6%**（0.16768 → 0.1617，seed 2021），
   即**诊断在该格判错**。按 §4.0 报告规则须列出全部判错格。
3. **Traffic 的 τ̂ 最低之一（25.1 步）**，与 E15 的发现（Traffic 的 `b_1` 一致落在 τ=168、
   `used_var_share(1)` 最高）**方向相反**。两者度量不同：
   `τ̂` 是*原始电平序列*的自相关时间，`b_1` 的 τ 是*最优线性映射输入方向*的核宽度。
   该差异须在 §4.7 表注显式说明，防止被读成矛盾。
4. **τ̂ 有 0.48–0.87 的系统性低估**（见 01_plan §4），只能作序数仪器。
