# PhaseFormer 输入成分 D5：广泛冻结利用验证结果

> 状态：完成。ETTm1、lookback=720、horizon=192、seed=2021、validation-only；从11,329个 validation
> origins 时间均匀抽取512个。无训练、无 test，GPU 前向约9秒。它是候选发现筛查，不是跨 seed 的正式
> 泛化结论。

## 1. 目的与判读

D5 用同一组 full-trained M0/M1/M2 checkpoint，一次性重测当前有效定义的15个输入成分：D1 六个
Gaussian spectral notch、D2 四个尾部置零、D3 五个末值锚定轨迹。它报告：

1. full→remove 的完整模型 MAE 变化；
2. 对 M1/M2 固定 full-input 相位预测和融合权重、仅替换 NLinear-style branch 的反事实 MAE 变化。

一个“原版未充分利用、NLinear 在利用”的候选至少要求：M0 的即时 remove 效应接近零，且 M1/M2 的
NLinear-only 反事实稳定为正并明显更大。较小的增强模型 remove 损失仅表示整体可恢复性，不能代替
这两个必要条件。

## 3. 结果解释

- **D1-32 和 D1-24 最接近“原版小效应”，但仍不是候选。** M0 的效应仅 +0.59% 和 +0.37%，不过 M1/M2
  的完整和 branch-only 效应也都约0.3--0.7%，没有模型分离。M0 的移动块95% CI 也分别为
  `[+0.36%, +0.91%]`、`[+0.14%, +0.62%]`，不能严格称为等效零。
- **D1 的主要频率是共同信息。** 96、48、约678、约206步的 remove 都令 M0 明显变差；M1/M2 branch
  也会变差，说明 NLinear 使用这些频率，但原版同样使用。
- **D2 的近期原始观测是共同且很强的信息。** 尾部窗口越长，三种模型越差；M0 从 +23.75% 增至
  +56.25%，绝不符合“原版未用”。RCRF 的 branch-only 效应接近 M2 整体效应，表明其 NLinear 路径
  对近期原始观测有直接作用，但这不构成 PhaseFormer 盲区。
- **D3 与 D4 一致。** `recent-linear` 和 `cycle-levels` 的既有结论被512样本筛查复现；M0 对二者强烈
  敏感。全局线性/相位漂移中 M1 的 NLinear branch 也显著使用被删轨迹，但 M0 仍有3--4%即时损失。

## 4. 决策

当前 D1/D2/D3 的15项已全部不满足目标模式，故**不应为它们追加多 seed 重训**。它们形成了一条更可靠的
负面证据：PhaseFormer 与增强路径共享对频率、近期观测及跨周期轨迹的利用；增强模型的 remove-trained
优势主要是补偿/恢复能力，而不能证明原版漏用某个已经命名的成分。

下一步若仍以“原版没用、增强在用”为目标，应不再从单独删除的显式输入成分出发，而应测试
**结构关系**：例如保留各时间点数值与频谱，却破坏“连续相邻时间点之间的相对顺序/局部差分关系”，并
保持 phase-slot 的跨周期统计量。它更直接针对24步 phase folding 与 NLinear 全时间轴映射的表示差异；
但需要先构造与扰动强度匹配的 control，不能直接宣称为下一阶段候选。
