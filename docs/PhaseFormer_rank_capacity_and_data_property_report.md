## 1. 方法：把"分支能做什么"精确化为数据问题

### 1.1 分支任务的精确等价（RevIN 抵消）

`direct_nlinear` 头做 `X - X_last → Linear(720,H) → + X_last`，`pooled_lowrank` 头
把同一个 `720→H` 映射写成 `decoder(encoder(·))`（`pool_factor=1` 时池化为恒等、
本轮 `smooth_ratio=0`）。记窗口为 `x`、真值为 `y`（均为 train-split
StandardScaler 之后的尺度），RevIN 逐窗口统计量为 `(mu, sigma)`：

```text
x_n = (x - mu)/sigma ,   x_n_last = (last - mu)/sigma
delta_n = W (x_n - x_n_last) = W (x - last)/sigma          # 头在归一化空间的输出
模型反归一化： sigma * delta_n = W (x - last)               # sigma 精确抵消
```

因此**分支在原始（scaler 后）单位下就是 `W(x - x_last)` 去拟合 `y - x_last`**，
逐窗口 RevIN 不引入任何近似。这也说明：按"原始增量"而非"归一化增量"做分析才与
模型损失的实际权重一致（否则窗口内近常数的通道会被 `1/sigma` 放大——早期版本按
归一化单位分折，Weather-96 的 persistence MSE 出现 10646 的假值，已修正）。

### 1.2 最优秩-r 解（reduced-rank regression）

在训练集上取二阶矩 `Szz=E[ZZ^T] (720×720)`、`Szy=E[ZD^T] (720×H)`、
`Syy=E[DD^T]`，`Z=x-x_last`、`D=y-x_last`。对 `min_{rank(W)≤r} E||D - WZ||²`
有闭式解：令 `S = Szy^T Szz^{-1} Szy`（H×H），取其前 r 个特征向量 `U_r`，

```text
W_r = U_r U_r^T Szy^T Szz^{-1}      （W_H = 最小二乘解）
```

推导：写 `W=AB`，固定 `A` 的最优 `B=(A^TA)^{-1}A^T G Szz^{-1}`（`G=E[DZ^T]=Szy^T`），
目标化为 `tr(Syy) - tr(P_A S)`，对 r 秩投影算子最大化 `tr(P_A S)` 即取 `S` 的前 r
个特征子空间。**`S` 的第 i 个特征值 `lambda_i` 恰好等于第 i 个方向买到的 MSE 降幅**
（`persistence_MSE - MSE(r) = Σ_{i≤r} lambda_i`，已在数值上逐 setting 校验到 1e-9）。
`W_r` 是"任何秩-r NLinear 分支在该分布上能达到的全局最优"，因此它给出容量代价的
**上界**。

### 1.3 为什么用 λ 谱而不是权重矩阵的奇异值

`W` 的奇异谱与"预测能力"不是一回事：H 行的矩阵秩天然 ≤ H，而且大量小奇异值方向
几乎不贡献 MSE 降幅。以 ETTh2-720 为例，最优映射的奇异值 95% 能量需要 418 个方向，
但**只有 8 个方向贡献 95% 的可实现降幅**。`PhaseFormer_lowrank_mechanism_analysis.md`
实验 1 测的是前者，容易被误读为"数据本身不低秩"；本报告的 λ 谱才是与压缩效应直接
对应的量。

### 1.4 指标定义

| 指标 | 含义 |
|---|---|
| `capture(r)` | `(MSE_persist − MSE_r) / (MSE_persist − MSE_full)` @val，即"相对 persistence 锚点的可实现提升中，秩 r 保留的比例"，>100% 表示该秩在 val 上优于满秩最优（满秩过拟合） |
| `pred_dims_90/95/99` | λ 谱达到 90/95/99% 累计份额所需方向数（训练集口径） |
| `PR` | λ 谱的 participation ratio `(Σλ)²/Σλ²`，即"有效预测维数" |
| `used_var_share` | 秩 r 映射行空间所占的"中心化窗口方差份额" |
| `rowspace_high_freq_frac` | 行空间基向量的高频能量占比（rfft 谱上半段；白噪声 = 0.5） |
| `lead_dir_*` | 秩 r 映射首个（最强）输入方向与全 1 向量 / 线性 ramp / 末 24 步指示向量的 \|cos\|，及其方差份额 |

### 1.5 验证（全部通过）

1. **λ 恒等式**：`persistence_MSE - MSE(r) = Σ_{i≤r} λ_i`。用 `--save-moments` 落盘的
   二阶矩在 7 个 setting × r∈{1,2,3,6}（共 26 个单元）上重算右式并与 CSV 的
   `train_mse` 对比，**checked 26 cells; worst absolute difference 4.72e-09**
   （`scripts/verify_optimal_rank_identity.py`，见 §5）。
2. **对照暴力解**：r=1 用交替最小二乘（8 次随机重启、400 步）求解，与 `W_r` 的
   MSE 完全相同（59.971509 vs 59.971509）；r≥2 时 ALS 因问题的病态性停在明显更差的
   局部解（例：r=2 时 ALS 102.1 vs `W_r` 22.4），故改用下面两条对照。
3. **对照随机投影**：200 个随机 r 秩投影算子从未优于 `S` 的前 r 特征子空间（r=1/2/3/6
   逐一验证）。
4. **对照 SVD 截断**：`W_OLS` 的截断 SVD 解从未优于 `W_r`（符合理论）。
5. **窗口数对齐**：脚本给出的 train/val 窗口数与 `metrics.csv` 记录的
   `train_size/val_size` 完全一致（如 ETTh2-96 = 7825/2785，Electricity-336 = 17357/2297）。
6. **两种独立口径互洽**：`capture(r_min)` 与 λ 谱的 `pred_dims_90/95` 在各 setting 上一致
   （例：ETTh2-96 `capture(3)=94.2%`，λ 谱 90% 需 3 维）。

## 3. 三个问题的结论

1. **能否基本保留性能？能，但"能"是分层的。**
   在"分支相对 persistence 锚点的可实现提升"这一口径下，本轮扫描测到的最深档位
   （q=1/32，分支参数降到满秩头的 3.5%–6.1%）仍保留 **92.4%–101.9%**（中位约 96%），
   因此 **容量不是这个数据集族里的瓶颈**：观测到的 test 差异（含深压缩一致偏害）
   不能归因于"秩不够"。但压缩并非字面无损：在预测性最强的 Electricity-336 上，最优
   秩-10 映射的分支残差仍比满秩高 26%（训练）/32%（val）；且整个分支占模型参数
   92.5%–99.9%，所以这是"几乎整模型级的参数压缩"。
2. **为什么能保留？三层原因，按解释力排序。**
   ① 任务的**预测结构本身低维**：λ 谱 PR 1.33–2.12，90% 的可实现提升只需 2–4 个方向，
   r=1 就拿到 65%–86%，r=3 拿到 88%–99%；② 超过该维数后新增的秩主要**拟合不可预测的
   高频噪声**（新增方向的高频占比从 0.14–0.37 升到 ~0.50，训练 MSE 继续降而 val 几乎不动），
   压缩砍掉的主要是"用不上"的容量；③ 融合结构把**分支误差按 g²≈0.04–0.26 折算**进报告
   指标，且秩约束下的训练还能重组出等价更优的低维解（机制分析文档），三者叠加使秩效应
   系统性小于 seed 噪声。
3. **被保留的性能对应数据中的什么性质？** 对应四条可测性质：
   (a) 存在**一个主导预测方向**（r=1 → 65%–86% 的收益），它只读取窗口增量方差的
   0.8%–12.3%；
   (b) 该方向是**低频的"近期水平 + 局部趋势"方向**（与末 24 步指示向量 \|cos\|=0.44–0.72，
   与线性 ramp \|cos\|=0.18–0.45，高频占比 0.14–0.37 < 0.5），即分支真正需要的是"当前
   水平相对 last 锚点的偏移与漂移方向"，而不是窗口的细节波形；
   (c) **窗口增量的绝大部分能量不可预测**：即使无约束映射也只覆盖 7.6%–60.7% 的中心化
   窗口方差（ETTh2-96 仅 13.3%）却已拿到 100% 可实现提升，因此"少读一些方向"几乎不损失；
   (d) 该结构**跨通道共享与否都能达到同样的低秩**（逐通道拟合在同样秩下与共享拟合
   相当，多数 setting 相差 ≤3 个百分点），因此共享低秩瓶颈不是"利用通道共性"的
   必要条件，而只是与之一致的设计选择。
   一个可判别性证据：预测维数需求最高的 Electricity-336 同时是"压缩最一致偏害"和
   "gate 唯一系统性关闭"的 setting，三者互相印证。

## 4. 边界与披露（不可省略）

- 7 个 setting 仍来自既有的 **test-set selection**；本报告的指标全部取
  **validation split**（非 test），因此不再叠加一次 test 暴露，但仍**不是**无偏泛化估计，
  不得作为提升声明。
- 本分析刻画的是**最优秩-r 映射**（容量上界），不是 SGD 实际找到的解；两者在
  Electricity-336 上已观察到差距（机制分析文档），因此"容量中性"不能直接外推为
  "任何秩-r 训练都是中性的"。
- 分支的目标函数被代理为标准化尺度上的平方误差；真实训练是融合输出上的 Huber 损失，
  且主干与 gate 同时可学。代理与真实目标在"哪些方向有用"上一致，但绝对数值不可直接
  与报告表格里的 test MSE 比较（单位不同：标准化 vs 原始）。
- gate 表来自 105 个审计 checkpoint（seeds 2021–2023 × 4 压缩档 + direct），
  `Δg` 的 seed 标准差与均值同阶者已标注为倾向性证据。
- 频段/方向统计为描述性指标（0.5 = 白噪声基准），不构成"某频段被物理删除"的因果结论；
  机制分析文档实验 4 的频段探针缺陷（扰动作用在公共输入而非分支私有输入）在本轮
  未重复。
- 本分析**不修改**任何 preset 默认值，也不改变任何历史结果口径。
