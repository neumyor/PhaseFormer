# HPTC：单一 PhaseFormer 的相位—轨迹—周期有机整合实验

> 状态：H96 validation-only 调参与样本审计已完成；预注册 gate 未通过，未运行 H192/test。
> 实验编号 `hptc_unified_v1`。

## 1. 已有证据与假设

已有结果给出四条直接约束：

1. A1（RCRF+NLinear）在 ETTh2/ETTm2 等 setting 更稳，说明全 horizon 轨迹不能被周期模型
   整体替换。
2. I0（RCRF+ICPT）在 12 个 H96/H192 setting 中有 8 个双指标优于 A1，尤其是 Weather、
   Electricity；但 ETTh2-H96 MSE 回退约 6.5%，说明周期间结构有效但适用域有限。
3. Rolling TriAxis 的历史首选命中率只有约 30.7%–41.8%，hard routing 和风险单调先验均
   失败，因此历史回测不适合承担离散选专家职责。
4. M3 soft ensemble 相对三个完整模型包络平均只再提高 0.79%，而 hard 版本全部失败；可利用
   信号更像连续误差修正，而不是可靠的完整模型选择。

据此提出假设：**把 NLinear 与 ICPT 的职责正交化，并把 rolling evidence 降级为连续收缩，
可以保留 NLinear 的周期水平/长期轨迹稳定性，同时只在历史支持时注入 ICPT 的周期间形状
修正，从而比并列专家路由更稳。**

## 2. 统一结构

模型只包含一个共享 PhaseFormer 和一个 checkpoint：

1. PhaseFormer 主干输出相位预测，负责周期内相位坐标和跨周期同相位关系。
2. NLinear 输出完整残差轨迹；它独占每个未来 24 步周期的均值/水平。
3. ICPT 只读取逐周期去均值的历史，并输出逐周期去均值的形状。最终修正严格投影到零均值
   子空间，因此不能改变 NLinear 的周期水平。
4. 多截点历史回测估计形状线性演化在相同 lead 上的平均误差与方差，只把 ICPT 形状修正
   连续收缩到 NLinear，不进行 expert argmax。
5. 外层继续使用 RCRF：相位可靠时偏向 PhaseFormer，相位不可靠时偏向上述统一残差预测。

形式上，若 `T` 是 NLinear，`S` 是 ICPT 形状，`Π₀` 表示逐未来周期去均值投影，则

`Y_res = T + β(X) · [S - Π₀(T)]`，且每周期 `mean(S - Π₀(T)) = 0`。

这不是 A1/I0/R0 的预测集成：没有三套 PhaseFormer、没有独立 checkpoint、没有完整模型
路由。NLinear、ICPT、rolling evidence 分别是一个可识别生成过程中的水平、形状和收缩项。

## 5. 必做消融与审计

- H0 对 H1：rolling evidence 是否比固定小修正更稳。
- H1/H2/H3：形状修正强度是否存在稳定区间。
- H2 对 H4：历史风险收缩强弱的作用。
- 校验每个未来周期的修正均值绝对值小于 `1e-6`，以及 flag-on/off 共享相位主干初始化。
- 对冠军相对 A1 回放全部 validation sample×channel，按绝对 MAE 差程序化选 baseline 高误差、
  candidate 退化、candidate 改善各 5 例，并分析 `β`、rolling risk、未来分段误差和输入形态。
- 报告参数量、单模型前向耗时；不得把 M3 ensemble 的计算或结果写成 HPTC 的模型贡献。

## 6. 样本审计结果

H4 对 A1 回放了六数据集共 1,121,992 个 validation 样本×通道。相对样本 MSE 改善至少 10%
的占 13.38%，退化至少 10% 的占 8.31%，其余占 78.31%。总体改善组的 lag-24 更高
（0.837 vs 0.771）、rolling risk 更低（0.909 vs 1.015），但该总体均值被 Electricity 的大量
通道主导，不能直接解释为可靠适用域。

- Electricity：改善/退化占比 16.68%/8.93%，四个未来 24 步区间都改善；但两组 lag-24 和
  risk 几乎相同，gate 本身没有很好地区分样本。
- ETTm1：改善/退化占比 12.82%/16.37%，远期 73–96 步 MAE 反而增加 0.87%。
- Weather：改善/退化占比 3.06%/6.21%；退化组 risk 反而比改善组低（1.014 vs 1.222），
  即当前 risk proxy 在这个关键数据集上出现反向置信。
- ETTh1/ETTh2 的收益随 horizon 变远而衰减，最后一个 24 步区间均转为轻微退化；ETTm2
  四段基本持平并小幅改善。

程序在每个 setting 内按绝对 MAE 选择 A1 高误差、H4 最大退化、H4 最大改善各 5 例，并对
同通道相距不足 96 的窗口去重。完整可审计工件在本地
`research_runs/hptc_unified_v1/`：报告 ZIP 只含 Markdown 和 7 张已引用中文图；388 MiB 的
全量 `sample_errors.csv`、checkpoint 和图片均由 `.gitignore` 排除，不提交到仓库。

checkpoint 回放与训练指标最大绝对差为 `3.05e-6`。逐周期修正理论上为零均值，但 float32
实测最大残差 `2.15e-6`，略高于预注册的 `1e-6` 数值检查阈值，已在审计中如实记为未通过。
H4 平均参数量 95,964，比 A1 的 72,803 增加 31.8%；相同 validation batch 的 GPU 前向耗时
为 A1 的约 2.06–2.78 倍。

## 7. 客观决策与下一步假设

本轮只部分支持原假设：严格分离轨迹水平与周期形状能控制 ICPT 风险，但“每个未来周期的
水平完全交给 NLinear”过强，可能删掉 Weather/远期 ETT 所需的周期级低频水平演化；而简单
形状线性外推 risk 与训练后 ICPT 的真实误差不一致。HPTC v1 不晋级正式 H192/test。

若继续，最有根据的单模型修改不是扩大 beta 或重新做完整模型路由，而是：在零均值形状之外
增加一个**受守恒约束、低秩且有幅度上界的周期级水平残差**，并用 ICPT 自身的历史 masked
reconstruction uncertainty 调节两种修正。这样仍是一套共享 PhaseFormer、一个 checkpoint，
但可直接验证当前审计暴露的两个缺陷。
