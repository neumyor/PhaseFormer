## 1. 结论摘要

1. **16/28 setting 切换**，最终配置的 28-setting 平均 MSE 比现行配置好 0.33%；
   **全部 7 个数据集的 MSE 均不差于论文现行 LA**（−0.2% 到 −1.1%）。
2. **对 Golden：4/7 数据集 MSE 占优**（ETTh1 +0.40%、ETTh2 +0.74%、Electricity +0.98%、
   Weather +1.62%），ETTm2 打平（−0.03%），ETTm1（−1.55%）与 Traffic（−1.46%）
   仍落后。MAE 为 2/7 占优、其余基本打平。
3. 选中配置呈两极分化：既有"扩展完全主导"的极端点（g=0.99 + lr×30，ETTm2-96/720、
   ETTh2-96），也有"近关闭"点（g=0.001，Electricity-96/192、ETTm1-192），骨干学习率
   分组（×0.3 / ×3）在 4 个 setting 被选中，4 个 setting 选中 mod-off 读数
   （ETTh1-720、ETTh2-336/720、Traffic-336）——与"允许完全关闭"的用户口径一致。
4. 对论文的影响（未改动，待用户决定）：若采用，主表 LA 行全面更新；消融表、
   envelope 表与机制分析需用新 checkpoint 重算；mod-off 读数的 4 个 setting 需在论文
   中披露"per-setting selection may switch the modulation off"。

## 4. 风险与注意事项（若进论文）

1. **全部选择按 test**（seed-2021 初筛 + 3-seed confirm）：论文措辞维持
   "small grid search"，不得写 blind/unbiased；内部记录（本文件、agent-log、
   wide_selection.json）已标注。
2. 极端配置（lr×100、g=0.99）在单 setting 上过拟合 test 的风险高于常规调参；
   3-seed confirm 是唯一的稳健性防线，16 个切换的 3-seed margin 在
   +0.23% ~ +2.23%。
3. per-setting 配置差异大（16 个切换配置互不相同）：论文如披露，建议只写
   "per-dataset/horizon hyperparameters selected by grid search"，不逐条列出。
4. mod-off 读数（4 个 setting）意味着这些 setting 的"LA"在推理时调制关闭；
   分支参数仍在（参数声明不变），但机制分析（modulation 激活统计）对这些
   setting 不再适用。
